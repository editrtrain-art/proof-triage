How a verdict is decided

Rules are tried in this order; the first that matches wins. A language model never decides.

check by handProof and a written blocker at once, a cited commit that does not exist, or a delivered URL that is gone.
dropThe task was moved elsewhere, or a sentence opens with “replaced by”, “cancelled because” or “migrated to”.
blocked on a personAn explicit blocker is written in the notes.
close, highA delivered file exists and a commit that touches that file exists.
close, mediumA delivered file exists, plus an unrelated commit or a delivered URL that answers.
check by hand, lowSome progress is visible but the proof is not enough.
rescheduleAn agent’s task with no evidence and no blocker.
